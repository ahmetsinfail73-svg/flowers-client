# Люкс Букет

Копия витрины lyuks-buket.topstore.pro на Next.js, React, Tailwind CSS и shadcn/ui (Base UI).

## Запуск

npm install
npm run dev

Адрес: http://localhost:3000. Production: npm run build, затем npm start.

Главная, каталог, карточка товара, корзина, подписка, доставка, о магазине, вход и регистрация. Каталог использует публичный demo API оригинала через серверный маршрут /api/catalog/products. Для другого API задайте NEXT_PUBLIC_SERVER_URL и STORE_API_KEY в .env.local.

Корзина сохраняется в localStorage. Оформление демонстрационное: без отправки в магазин и без оплаты. Вход и регистрация представлены формами с валидацией, серверная авторизация не подключена. Контактные ссылки ведут на оригинальный магазин.

Компоненты shadcn: src/components/ui/common. Общая тема: src/app/globals.css. Тексты: src/constants/config.constant.ts.
# Подсказки адресов Казани

Подсказки на странице оформления заказа загружаются через серверный маршрут `/api/address-suggestions/` из [DaData](https://dadata.ru/api/suggest/address/). Укажите `DADATA_API_KEY` в `.env.local` и перезапустите приложение. Ключ остаётся на сервере. Поиск ограничен Казанью. Одинаковые запросы к DaData кэшируются на сервере на 24 часа, а ввод отправляется с задержкой 350 мс. Квартиру покупатель указывает вручную. Если адрес отсутствует в подсказках, его можно ввести вручную.
